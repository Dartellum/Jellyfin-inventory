# 🎬 Jellyfin Media Library Auditor & Inventory Tracker

An automated Python tool to audit, organize, and inventory your **Jellyfin / Emby / Plex** movie and TV show libraries against **The Movie Database (TMDb)** API.

Generates a formatted Microsoft Excel (`.xlsx`) audit report detailing collection completeness, TV show seasons, episode counts, folder payload sizes, video quality deductions, upgrade recommendations, and barcode (UPC) tracking.

---

## 🌟 Key Features

- **Franchise / Collection Gap Detection**:
  - Automatically identifies whether a movie belongs to a franchise or collection (e.g., *The Matrix Collection*, *The Lord of the Rings*, *Harry Potter*).
  - Lists missing sequels, prequels, and installments so you know exactly which discs you are missing.

- **Granular TV Series & Season Auditing**:
  - Checks broadcast seasons and bonus specials (*Season 0*).
  - Accurately matches seasons via regex (e.g., `Season 01`, `S01`, `Specials`).
  - Audits episode counts (e.g., `✓ Found (13 eps)` or `✓ Found (Partial: 2/10 eps)`).
  - Flags empty directories that need to be populated (`✕ Empty (0 eps)`).
  - Accurately differentiates classic and reboot runs with identical titles (e.g., *Doctor Who (1963)* vs *Doctor Who (2005)*).

- **Format Quality Analysis & Upgrade Guidance**:
  - Deduces video source quality from file/folder payload sizes and average episode sizes:
    - `[DVD / SD]`
    - `[1080p Encode / Web-DL]`
    - `[1080p Blu-ray (Remux)]`
    - `[4K Ultra HD]`
  - Provides actionable upgrade recommendations (e.g., *"Recommendation: Upgrade to uncompressed 1080p Blu-ray (Remux) or 4K UHD"*).

- **UPC Barcode Persistence**:
  - Automatically reads the previous audit report on each run and preserves any barcode (UPC) scans previously logged.
  - Formats UPC cells as text to prevent Excel from dropping leading zeros or converting numbers to scientific notation.

- **Formatted Excel Reports**:
  - Freezes header rows for smooth scrolling.
  - Auto-enables sorting and filtering dropdowns.
  - Automatically sizes column widths to fit content.
  - Applies conditional red highlighting to missing films, missing seasons, and empty folders.

## 📁 Expected Directory Structure

Follows the standard [Jellyfin / Plex Media Preparation Guidelines](https://jellyfin.org/docs/general/server/media/movies/):

```text
Entertainment/
├── Movies/
│   ├── The Matrix (1999) [imdbid-tt0133093]/
│   │   └── The Matrix (1999).mkv
│   └── Inception (2010) [imdbid-tt1375666]/
│       └── Inception (2010).mkv
└── TV-Shows/
    ├── Doctor Who (2005) [imdbid-tt0436992]/
    │   ├── Season 00/
    │   ├── Season 01/
    │   │   ├── Doctor Who (2005) - S01E01 - Rose.mkv
    │   │   └── ...
    │   └── Season 02/
    └── Severance (2022) [imdbid-tt11280740]/
        └── Season 01/
```

## 🚀 Quick Start

### 1. Prerequisites
- Python 3.8+
- A free [The Movie Database (TMDb)](https://www.themoviedb.org/) account

### 2. Installation
Clone this repository and install dependencies:

```bash
git clone https://github.com/your-username/jellyfin-inventory.git
cd jellyfin-inventory
pip install -r requirements.txt
```

### 3. Configuration
Copy the example environment template to `.env`:

```bash
cp .env.example .env
```

Open `.env` and configure your TMDb token and library path:

```ini
# TMDb API v4 Read Access Token
# Obtain yours from: https://www.themoviedb.org/settings/api
TMDB_V4_TOKEN="your_tmdb_v4_read_access_token_here"

# Path to the root directory containing 'Movies' and 'TV-Shows'
MEDIA_LIBRARY_DIR="/path/to/your/Entertainment"
```

> **Security Note:** `.env` is included in `.gitignore` by default. Never commit your API token or secret keys to version control.

### 4. Run the Audit
Run the script from the project folder:

```bash
python3 media_list.py
```

The script will:
1. Preserve any existing UPC barcodes from the latest audit file.
2. Scan your `Movies` directory and query TMDb for franchise collections.
3. Scan your `TV-Shows` directory and check seasons, episode counts, and sizes.
4. Export the results into a timestamped file: `Jellyfin_Audit_List_YYYY-MM-DD_HH-MM-SS.xlsx`.
